# DataManagementFundamentalsABL_Apps
Static web app (no build step) with in-workshop activities for the Level 4 Data Management Fundamentals module, aligned with Activity-Based Learning (ABL): do → check → reflect.

Activities: data types, data quality, keys & normalisation, and a reflection log.

Run: open `index.html` in a browser, or `python3 -m http.server` and visit http://localhost:8000.
